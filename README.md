# DNS Switcher Script

This interactive script allows you to easily switch between different DNS providers. It is compatible with both **Linux** 🐧 and **macOS** .

## Usage

### Clone the Repository

```bash
git clone https://github.com/Mr-Meshky/dns-switcher.git
cd dns-switcher
```

### Install the Script

```bash
chmod +x install.sh
./install.sh
```

### Run the Script

After installation, run the script using the alias:

```bash
change-dns
```

## Supported Operating Systems

- **Linux**
- **macOS**

## Custom DNS

Add custom DNS providers by selecting the **Add Custom DNS** option from the menu.
